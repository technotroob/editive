# ✦ EDITIVE

### Create. Edit. Unlock. Reframe.

> A modern, beginner-friendly web image editor that combines professional editing tools, AI-powered image manipulation, and intelligent workflows for working with visual designs.

---

## 🎨 Overview

EDITIVE is a browser-based image editor designed to make powerful visual editing easier to discover and use.

It combines essential image-editing capabilities with AI-powered tools and intelligent workflows that help users create, modify, enhance, and repurpose visual content.

The core idea behind EDITIVE is simple:

> **You have the image. You need the design. EDITIVE bridges the gap.**

EDITIVE is designed for users who want to create designs from scratch, edit existing images, enhance visual content with AI, and regain control over flattened visual designs.

---

## ✦ The Problem

In real-world design workflows, users often have the final exported image but not the original editable design.

They may only have:

- JPG files
- PNG files
- Screenshots
- Posters
- Social media creatives
- Advertisements
- Product graphics
- Menus
- Exported designs
- Other flattened visual assets

Normally, modifying these assets can mean rebuilding the design from scratch.

EDITIVE introduces another workflow:

```text
Finished Image
      ↓
    EDITIVE
      ↓
Unlock / Edit / Enhance
      ↓
Reframe / Restyle
      ↓
  Final Design
```

# 🔓 Unlock Design

## The EDITIVE Difference

One of EDITIVE's key capabilities is **Unlock Design**.

The concept is simple:

> **What if you only have the final image but still want to edit the design?**

Instead of immediately rebuilding the entire design manually, EDITIVE attempts to analyze the flattened image and reconstruct supported visual regions into editable elements.

### 🔄 Workflow

```text
             FLAT IMAGE
                  │
                  ▼
               ANALYZE
                  │
                  ▼
           DETECT ELEMENTS
                  │
                  ▼
                REVIEW
                  │
                  ▼
          EDITABLE ELEMENTS
                  │
                  ▼
           NORMAL EDITING
```

Potentially detected elements include:

- Text
- Image Regions
- Shapes
- Logo-like Elements
- Background

### 🧩 Manual Reconstruction

Automatic detection may not always identify every element perfectly.

EDITIVE therefore provides a manual fallback:

```text
Select Region
      ↓
Draw Region
      ↓
Convert to Layer
      ↓
Continue Editing
```

This allows users to manually recover regions that require correction.

### 🔄 Before & After

```text
BEFORE

┌──────────────────────────────┐
│                              │
│        FLATTENED IMAGE       │
│                              │
│   Everything exists as one   │
│          visual asset        │
│                              │
└──────────────────────────────┘


AFTER

┌──────────────────────────────┐
│ Background                   │
├──────────────────────────────┤
│ Headline                     │
├──────────────────────────────┤
│ Product / Image              │
├──────────────────────────────┤
│ Shape                        │
├──────────────────────────────┤
│ CTA                          │
├──────────────────────────────┤
│ Logo                         │
└──────────────────────────────┘
```

The goal is to transform a flat visual asset into a more editable structure.

# 🖼️ PSD Support

EDITIVE is designed to support working with Photoshop documents where technically supported.

- Canvas Dimensions

Unsupported Photoshop features may be flattened or represented with reduced editability.

## PSD Export

Where technically supported, EDITIVE can export project information into a PSD-compatible structure.

Supported information may include:

- Canvas Dimensions
- Layer Structure
- Layer Names
- Layer Ordering
- Images
- Text
- Opacity
- Supported Blend Modes

EDITIVE does not simply rename an image file and call it a PSD.

# ⚙️ Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/editive.git
cd editive
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Configure Environment Variables

Create:

```text
.env.local
```

Add the required AI API credentials:

```env
REMOVE_BG_API_KEY=
CLIPDROP_API_KEY=
OCR_SPACE_API_KEY=
REPLICATE_API_TOKEN=
```

Use the environment variables required by the integrations enabled in your local setup.

---

# 🔐 Security

## Never Commit API Keys

Real API keys and secrets must never be committed to GitHub.

Keep sensitive credentials inside:

```text
.env.local
```

For production deployments, configure secrets through Vercel Environment Variables.

Never expose private API credentials through:

- Client-side React components
- `NEXT_PUBLIC_*` variables
- Local storage
- Public configuration
- GitHub repositories
- README files
